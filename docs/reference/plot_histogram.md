# Histograms with density function

Histograms with density function

## Usage

``` r
plot_histogram(
  df,
  bins = 30,
  title = "",
  base_size = 10,
  xlims = NULL,
  fill = "gray25",
  color = "gray50",
  ylab = "Count"
)
```

## Arguments

- df:

  dataframe or vector with continous or ordinal data

- bins:

  number of bars to display

- title:

  plot title

- base_size:

  numeric base font size

- xlims:

  x axis limits

- fill:

  color of bar

- color:

  color of bar outline

- ylab:

  y label

## Details

uses ggplot
