# qq plots

qq plots

## Usage

``` r
plot_qq(df, title = "", base_size = 10)
```

## Arguments

- df:

  dataframe or vector with continous or ordinal data

- title:

  plot title

- base_size:

  numeric base font size

## Details

uses ggplot
