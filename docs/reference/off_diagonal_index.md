# index of off diagonal

index of off diagonal

## Usage

``` r
off_diagonal_index(length)
```

## Arguments

- length:

  length of diagonal

## Examples

``` r
off_diagonal_index(length=6)
#>   x1 x2 x3 x4
#> 1  1  1  2  0
#> 2  2  2  3  1
#> 3  3  3  4  2
#> 4  4  4  5  3
#> 5  5  5  6  4
#> 6  6  6  7  5
```
