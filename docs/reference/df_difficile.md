# Difficile Data

This data set contains information about the impact of different doses
on libido.

## Usage

``` r
df_difficile
```

## Format

A data frame with 15 rows and 3 variables:

- person:

  Unique identifier for each person

- dose:

  Dose received (e.g., 1, 2, 3)

- libido:

  Libido level of the person
