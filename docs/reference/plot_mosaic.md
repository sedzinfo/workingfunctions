# Plot mosaic plots

Plot mosaic plots

## Usage

``` r
plot_mosaic(df, factor_index, base_size = 10, title = "")
```

## Arguments

- df:

  dataframe

- factor_index:

  index of factors

- base_size:

  base font size

- title:

  plot title
