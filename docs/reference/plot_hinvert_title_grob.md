# Invert a title grob horizontally

Helper used by `duplicate_y_axis` to mirror a grob's width layout and
text alignment so it renders correctly on the right-hand side of a plot.

## Usage

``` r
plot_hinvert_title_grob(grob)
```

## Arguments

- grob:

  A grob object (titleGrob or similar) to invert.

## Value

The modified grob.
