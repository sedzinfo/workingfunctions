# Convert UNIX EXCEL timestamp

Convert UNIX EXCEL timestamp

## Usage

``` r
convert_excel_unix_timestamp(timestamp)
```

## Arguments

- timestamp:

  unix or excel timestamp

## Examples

``` r
convert_excel_unix_timestamp(1)
#> $unix_timestamp
#> [1] -2209075200
#> 
#> $excel_timestamp
#> [1] 24107
#> 
```
