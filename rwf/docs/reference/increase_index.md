# index dataframe picks

index dataframe picks

## Usage

``` r
increase_index(blocks, items)
```

## Arguments

- blocks:

  number of blocks

- items:

  number of items per block

## Examples

``` r
increase_index(3,3)
#>      [,1] [,2] [,3]
#> [1,]    1    2    3
#> [2,]    4    5    6
#> [3,]    7    8    9
```
