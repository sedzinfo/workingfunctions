# Scree plot displaying the Kaiser and Jolife criteria for factor extraction

Scree plot displaying the Kaiser and Jolife criteria for factor
extraction

## Usage

``` r
plot_scree(df, base_size = 15, title = "", color = c("#5F2C91", "#5E912C"))
```

## Arguments

- df:

  dataframe

- base_size:

  base font size

- title:

  plot title

- color:

  color of line and point outline

## Examples

``` r
plot_scree(df=mtcars,title="",base_size=15)
```
